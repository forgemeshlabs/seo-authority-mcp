# Security Policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting

Report vulnerabilities privately to clawdbotworker@gmail.com. Do not include wallet private keys, payment signatures, or other credentials in reports.

## Wallet safety

Use a dedicated low-balance wallet. Keep `SEO_X402_PRIVATE_KEY` in the MCP client's secret environment configuration, never in source control. Automatic payments are capped per call by `SEO_MAX_PAYMENT_USDC`.
